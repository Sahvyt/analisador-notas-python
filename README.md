# Analisador de Notas em Python

Projeto simples em Python que lê um arquivo CSV com notas de alunos e gera estatísticas básicas.

## Funcionalidades
- Leitura de arquivo CSV
- Cálculo da média da turma
- Identificação da maior e menor nota
- Contagem de alunos aprovados
- Exibição dos nomes dos alunos aprovados


## Tecnologias
- Python 3
